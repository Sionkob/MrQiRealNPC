# Mister Qi is a Real NPC
[Mister Qi is a Real NPC](https://www.nexusmods.com/stardewvalley/mods/16724) is a Content Patcher mod that turns Mister Qi into a giftable NPC by adding him as a custom NPC. The mod introduces a new story for the character while respecting Mister Qi's original personality.

# Requirements
This mod requires the following mod to work:
- [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915) - By Pathoschild

The mod will not work without Content Patcher installed.

# Installation and Uninstallation Instructions
To install the mod, follow these steps:
- Download the mod from [GitHub](https://github.com/Sionkob/MrQiRealNPC/releases) or [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/16724);
- Extract the contents of the downloaded ZIP file into your Mods folder.

To uninstall the mod, follow the step below:
- Remove the **[CP] Mister Qi is a Real NPC** folder from your Mods folder.

# What This Mod Adds?
The mod is currently in beta; some features or content may change. At the moment, this mod adds:
- A new version of the NPC Mr. Qi that you can unlock the option to get married with;
- Over 230 lines of dialogue, including marriage lines and edits to other NPCs' dialogues;
- 16 exclusive events, including heart events and secret events;
- 3 new locations, two of which have been completely redesigned;
- Mr. Qi now has his own spouse room and spouse patio when married;
- New sprites and portraits for Mr. Qi;
- Schedules for Mr. Qi, including marriage schedules;
- Expands the vanilla game lore by exploring loose ends in the game;
- Rewrites Mr. Qi's backstory;

For more details about events, gift tastes, movies & concessions tastes, and other information, check out the mod wiki by visiting this [article](https://www.nexusmods.com/stardewvalley/articles/4309) on Nexus Mods.
