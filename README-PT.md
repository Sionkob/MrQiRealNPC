# Senhor Qi é um Verdadeiro NPC
[Senhor Qi é um Verdadeiro NPC](https://www.nexusmods.com/stardewvalley/mods/16724) é um mod Content Patcher que transforma o Senhor Qi em um NPC presenteável adicionando ele como um NPC personalizado. O mod traz uma história nova para o personagem respeitando a personalidade original do Senhor Qi.

# Requisitos
Este mod precisa do seguinte mod para funcionar:
- [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915) - Feito por Pathoschild.

Sem o Content Patcher instalado, o mod não funcionará.
  
# Instruções de instalação e desinstalação
Para instalar o mod, siga os passos abaixo:
- Baixe o mod pelo [GitHub](https://github.com/Sionkob/MrQiRealNPC/releases) ou [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/16724);
- Extraia o conteúdo do arquivo ZIP baixado para a pasta Mods.

Para desinstalar o mod, siga o passo abaixo:
- Remova a pasta **[CP] Mister Qi is a Real NPC** da pasta Mods.

# O que este mod adiciona?
O mod está em fase beta; alguns recursos ou conteúdos podem sofrer alterações. Atualmente, este mod adiciona:
- Uma nova versão do NPC Sr. Qi que você pode desbloquear a opção de se casar;
- Mais de 230 linhas de diálogo, incluindo linhas de casamento e edições nos diálogos de outros NPCs;
- 16 eventos exclusivos, incluindo eventos de coração e eventos secretos;
- 3 novos locais, 2 deles foram completamente repaginados;
- Sr. Qi agora tem seu próprio quarto e área do cônjuge ao se casar;
- Novos sprites e retratos para o Sr. Qi;
- Cronogramas para o Sr. Qi, incluindo cronogramas de casamento;
- Expande a lore do jogo vanilla, explorando pontas deixadas em aberto no jogo;
- Reescreve a backstory do Sr. Qi;

Para saber mais detalhes sobre eventos, gostos de presentes, gostos de filmes e lanches e outras informações, confira a wiki do mod acessando este [artigo](https://www.nexusmods.com/stardewvalley/articles/4298) no Nexus Mods.
